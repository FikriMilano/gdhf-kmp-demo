FHIR Foundations

Six libraries, one codebase.

The demo uses forms, FHIRPath calculations, extraction, on-device storage, search and sync, all from shared Kotlin code. Tap a library to open it on GitHub.

  • Kotlin FHIRkotlin-fhir FHIR resource models: R4, R4B, R5 RC
  • Kotlin FHIRPathkotlin-fhirpath FHIRPath engine, official test suite BETA
  • Data Capturekotlin-fhir-data-capture Questionnaire rendering and response capture ALPHA
  • Enginekotlin-fhir-engine On-device storage and sync ALPHA
  • Workflowkotlin-fhir-workflow Clinical decision support and measures ALPHA
  • Knowledgekotlin-fhir-knowledge Loading and managing implementation guides ALPHA

Build with AI

Your coding agent, fluent in FHIR.

OHS agent skills teach Antigravity, Claude and Codex to build on the tested FHIR Foundations libraries instead of writing FHIR code from scratch. Standards compliance comes with the foundations.

Antigravity CLI

Run in your terminal.

$ agy plugin install https://github.com/ohs-foundation/agent-skills

Claude Code

Run as two separate prompts in Claude Code.

$ /plugin marketplace add ohs-foundation/agent-skills
$ /plugin install ohs@agent-skills

Codex

Run in your terminal.

$ codex plugin marketplace add ohs-foundation/agent-skills
$ codex plugin add ohs@agent-skills

Part of AI Commons, the Open Health Stack pillar for safe, verifiable AI in global health.
